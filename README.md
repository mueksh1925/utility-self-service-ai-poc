A learning Proof of Concept built using IBM watsonx.ai.

## Technologies

- Angular 20
- FastAPI
- IBM watsonx.ai
- IBM Granite
- IBM watsonx Assistant
- Retrieval-Augmented Generation (RAG)

- Billing Assistant
- Power Outage Assistant
- Service Requests
- Appointment Scheduling
- AI-powered Customer Support
